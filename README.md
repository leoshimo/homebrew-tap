# Homebrew tap

Prebuilt macOS tools from [leoshimo](https://github.com/leoshimo).

```sh
brew install leoshimo/tap/ditooctl
brew upgrade leoshimo/tap/ditooctl
```

`ditooctl` controls an original Divoom Ditoo. Requires macOS 13+ on Intel or Apple Silicon. Pair the device on the Mac running the command.

[CLI usage and releases](https://github.com/leoshimo/ditooctl).
